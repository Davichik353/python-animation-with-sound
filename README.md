# Анимация со звуком

Для точного воспроизведения исходного ролика откройте папку репозитория и выполните две команды.

```sh
python -m pip install -r requirements.txt
python animation.py
```

Понадобится Python 3.10 или новее. Скрипт сохранит `animation.mp4` в текущей папке. Его можно открыть в VLC или другом проигрывателе с поддержкой HEVC. Скрипт использует FFmpeg из системы или из пакета imageio-ffmpeg. Рисунки и оригинальная звуковая дорожка входят в репозиторий.

## Рисованная версия

Скрипт `draw_animation.py` рисует персонажей, фон и субтитры средствами Python. После установки зависимостей запустите его с оригинальной фонограммой из репозитория.

```sh
python draw_animation.py assets/sound.m4a -o drawn_animation.mp4
```

Чтобы взять звук непосредственно из исходного видео, вместо `assets/sound.m4a` укажите путь к своему MP4.

## Как устроена анимация

В 17 сценах расставлены 166 ключевых поз. Между позами Python рассчитывает положение и размер слоёв с персонажами, совмещает их с фоном и добавляет надписи. На границах сцен меняется весь кадр. Слой разницы восстанавливает мелкие движения, частицы снега и дождя, цвет, зерно и контуры букв до исходной точности.

В результате получается 979 кадров размером 1280 × 720 с частотой 30 кадров в секунду. Исходная стереодорожка AAC скопирована целиком. Звук продолжается ещё около 0,17 секунды после видеодорожки, как в оригинале.

## Как изменить рисунки и движение

Цветные PNG лежат в `assets/drawings`. Для каждой ключевой позы в `assets/timeline.json` указан номер кадра и прямоугольник каждого слоя в формате `[x, y, ширина, высота]` на холсте 640 × 360. Начало координат находится в левом верхнем углу. Например, чтобы изменить шаг героя на закате, отредактируйте слой `hero` в сцене `walk`. Положение текста задаёт слой `caption`.

После правки рисунков или координат соберите свою версию отдельной командой. Она использует отредактированные слои и сохраняет ту же фонограмму.

```sh
python animation.py --drawings-only -o my_animation.mp4
```

Обычный запуск использует `assets/detail.h264` со значениями разницы для исходных рисунков. Фонограмма лежит в `assets/sound.m4a`.
